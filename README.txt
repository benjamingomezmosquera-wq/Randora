# RANDORA — sitio web
Abrí `index.html` en un navegador.

Incluye:
- 20 productos tomados del archivo base de RANDORA.
- Precios y stock del catálogo.
- Buscador y ordenamiento.
- Filtros por sucursal.
- Carrito funcional con localStorage.
- Selector de tema: violeta, azul, amarillo/dorado y blanco/negro.
- Sección sobre RANDORA basada en el documento de preguntas.
